#+title: macOS Background Task Manager (BTM)

* Quick Reference

Database location: /var/db/com.apple.backgroundtaskmanagement/BackgroundItems-v13.btm (Binary Plist; `v13` may be some other version).


* About

- Consolidates background tasks (LaunchAgent, LaunchDaemon, LoginItem) installed through `SMAppSerivce` and its predecessors.
- Notifies user on installation of background tasks, and provides user ability to enable/disable via System Preferences.
- Can be listed with: `sudo sfltool dumpbtm`
